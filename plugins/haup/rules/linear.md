# Linear is intake, not history

Finished Linear tickets are trashed. Linear holds only work that is still open.

- Never link issues to each other: no `relatedTo`, `blocks`, `blockedBy` or `duplicateOf`. Never try to, and never report a link that failed.
- Name past work by its ticket key in plain text (e.g. "the fix from HAU-611"). For what it did, read the repo's `docs/handoff/` notes and the git log, not Linear.
- Do not look up a past ticket in Linear to get context. A missing or trashed ticket is expected, not something to report.
