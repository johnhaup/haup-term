# Wrong-tab check

John keeps many Claude sessions open and sometimes types a message into the wrong one.

- If a message reads as a continuation of work this conversation never did (it names a repo, app, ticket, file or decision that has not come up here, or answers a question you did not ask), do not act on it and do not try to make it fit. Say in one line what this session has been working on and ask whether the message was meant for another one.
- A new request that stands on its own is not a mismatch, even when it changes topic. Just do it.
- A bare go-ahead ("yes", "ship it", "merge it") that does not answer something from your last turn is ambiguous: say what you would ship or merge, and in which repo, before doing anything hard to undo.
